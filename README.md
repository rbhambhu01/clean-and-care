# Clean & Care — Website + Backend

A full-stack recreation of the Clean & Care laundry/dry-cleaning marketing site:
same navigation, sections, service list, full pricing table, testimonials and
contact/pickup flows, rebuilt as a React frontend backed by a small Node/Express
API. Visual design (lime-green `#B0CB1F` accent, black header/footer, cream
section backgrounds, serif headings over sans body text, pill buttons, circular
icon badges) matches the original; photography was **not** copied — placeholder
graphics stand in for the original's proprietary photos so you can drop in your
own.

## Stack

- **backend/** — Node.js, Express, JSON file database (`lowdb`), JWT-based
  admin auth, bcrypt password hashing.
- **frontend/** — React 18, Vite, Tailwind CSS, React Router, lucide-react icons.

## Project layout

```
backend/
  server.js        # Express app entry point
  db.js             # lowdb JSON database wrapper
  seed.js           # seeds company info, services, pricing, testimonials, blog, admin user
  routes/
    public.js        # GET company/services/pricing/testimonials/blog
    contact.js        # POST /contact and /schedule-pickup (public leads)
    auth.js            # POST /auth/login (admin)
    admin.js            # JWT-protected CRUD + lead viewing
  middleware/auth.js    # JWT verification middleware
  data/db.json           # generated by `npm run seed` (gitignored)

frontend/
  src/
    pages/            # Home, About, Services, Pricing, Career, Franchise, Contact, Admin
    components/        # Navbar, Footer, ServiceCard, IconBadge, StarRating, SectionHeading
    context/             # CompanyContext (fetches company info once, shares via React context)
    api.js                # fetch wrapper for the backend API
```

## Setup

### 1. Backend

```bash
cd backend
npm install
cp .env.example .env    # edit ADMIN_USERNAME / ADMIN_PASSWORD / JWT_SECRET
npm run seed             # populates data/db.json with company, services, pricing, testimonials, blog, admin user
npm run dev               # starts the API on http://localhost:4000 (auto-restarts on change)
```

The seed script prints the admin login it created, e.g.:

```
Admin login -> username: admin, password: change-this-password
```

**Change `ADMIN_PASSWORD` and `JWT_SECRET` in `.env` before any real deployment.**

### 2. Frontend

```bash
cd frontend
npm install
npm run dev     # starts Vite dev server on http://localhost:5173, proxying /api to :4000
```

Visit `http://localhost:5173`. The dev server proxies all `/api/*` calls to the
backend (see `frontend/vite.config.js`), so both must be running together.

### 3. Production build

```bash
cd frontend
npm run build     # outputs static files to frontend/dist
```

Serve `frontend/dist` with any static host (Nginx, Vercel, Netlify, etc.) and
point it at your deployed backend by adjusting the API base URL or reverse-proxying
`/api` to the Express server, the same way the Vite dev proxy does.

## What's included

- **Public pages**: Home, About Us, Services, Pricing (full item-level price
  table scraped from the original site: Men's/Women's/Kids/Home DC & Steam
  Iron pricing, by-weight laundry, shoe spa, add-ons), Career, Franchise,
  Contact Us.
- **Contact & pickup forms**: `POST /api/contact` and `POST /api/schedule-pickup`
  validate input, store leads in the database, and return a confirmation message
  shown in the UI.
- **Admin dashboard** (`/admin` route in the frontend): login with the seeded
  admin credentials to view submitted contact messages and pickup requests.
  The backend also exposes CRUD endpoints for services/testimonials/blog posts
  under `/api/admin/*` (JWT-protected) if you want to extend the dashboard UI
  to manage that content.

## API reference

| Method | Path                         | Auth  | Purpose                          |
|--------|------------------------------|-------|-----------------------------------|
| GET    | `/api/company`               | —     | Company info, about copy, address |
| GET    | `/api/services`               | —     | List of services                  |
| GET    | `/api/pricing`                 | —     | Pricing categories + extras       |
| GET    | `/api/testimonials`             | —     | Customer testimonials             |
| GET    | `/api/blog`                      | —     | Blog posts                        |
| POST   | `/api/contact`                    | —     | Submit a contact message          |
| POST   | `/api/schedule-pickup`             | —     | Submit a pickup request           |
| POST   | `/api/auth/login`                   | —     | Admin login, returns JWT          |
| GET    | `/api/admin/leads/contact`           | JWT   | List contact messages             |
| GET    | `/api/admin/leads/pickup`             | JWT   | List pickup requests              |
| PATCH  | `/api/admin/leads/pickup/:id`          | JWT   | Update pickup status              |
| POST/PUT/DELETE | `/api/admin/services`, `/testimonials`, `/blog` | JWT | Manage content |

## Notes for going live

- Swap the placeholder hero/about imagery in `frontend/src/pages/Home.jsx` for
  your own product photography.
- Update `backend/seed.js` company contact details (address/phone/email) if
  anything changes, then re-run `npm run seed` (this resets leads too — back up
  `data/db.json` first if you want to keep submitted leads).
- For real traffic, move the lowdb JSON store to a proper database (e.g.
  SQLite with `better-sqlite3`, or Postgres) — the current setup is simple and
  file-based, by design, for fast local setup.
